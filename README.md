# send21

Direct. Non-custodial. Yours.

send21 prepares payment drafts and pay links for BTC, USDC, USDT, and EURC on Bitcoin, Solana, Ethereum, and Base (no USDT or BTC on Base). You sign in your own wallet. send21 never holds keys, never signs, and never broadcasts.

- Site: https://send21.io
- OpenAPI: https://send21.io/swagger/v1/swagger.json
- MCP: https://send21.io/mcp
- llms.txt: https://send21.io/llms.txt
- X: https://x.com/send21io
- Contact: info@send21.io

Not a wallet. Not an exchange. Not a payment processor.
